# 快速開始

歡迎！本指南將幫助你在 5 分鐘內開始遊戲。

## 快速啟動

### 1. 啟動虛擬環境

```bash
# Windows
myenv\Scripts\activate

# Linux/Mac
source myenv/bin/activate
```

### 2. 執行遊戲

```bash
python main.py
```

### 3. 開始遊戲

1. 在主選單選擇「計時模式」
2. 選擇難度（初級/中級/專家級）
3. 開始遊戲！

## 基本操作

### 遊戲操作

- **左鍵點擊**：揭開格子
- **右鍵點擊**：標記/取消標記地雷
- **數字**：顯示周圍地雷數量

### 遊戲目標

- 揭開所有非地雷的格子
- 標記所有地雷
- 盡可能快速完成！

## 遊戲技巧

### 初學者技巧

1. **從角落開始**：角落通常比較安全
2. **觀察數字**：數字告訴你周圍有多少地雷
3. **使用邏輯**：如果數字 1 旁邊只有一個未揭開的格子，那一定是地雷
4. **標記地雷**：右鍵點擊標記你認為是地雷的格子

### 進階技巧

1. **模式識別**：學習常見的數字模式
2. **機率計算**：當無法確定時，選擇機率較低的格子
3. **效率優先**：快速標記確定是地雷的格子

# 功能介紹

詳細介紹踩地雷 AI 教學遊戲的各項功能。

## 已實現功能

### ✅ 計時模式

**功能描述**：
單人計時遊戲模式，記錄完成時間並支援排行榜。

**特色**：
- 三種難度等級（初級/中級/專家級）
- 即時計時器（從第一次點擊開始）
- 移動次數統計
- 排行榜系統（SQLite 資料庫）
- 遊戲勝利後可儲存成績

**使用方式**：
1. 主選單選擇「計時模式」
2. 選擇難度
3. 開始遊戲並盡可能快速完成

### ✅ 遊戲引擎

**功能描述**：
完整的踩地雷遊戲邏輯實現。

**特色**：
- 隨機地雷生成
- 第一次點擊安全保證
- 自動展開空白區域
- 完整的勝利/失敗判斷
- 地雷數量計算

### ✅ AI 機率計算

**功能描述**：
計算每個格子的地雷機率，為未來的教學模式做準備。

**特色**：
- 約束傳播算法
- 多約束條件整合
- 機率計算引擎
- 安全格子識別
- 地雷格子識別

**技術**：
- 使用約束滿足問題（CSP）方法
- 考慮多個數字方塊的共同約束
- 提供詳細的推理過程（未來擴展）

### ✅ 排行榜系統

**功能描述**：
SQLite 資料庫儲存和管理遊戲記錄。

**特色**：
- 按難度分類
- 顯示最佳時間
- 玩家名稱記錄
- 日期時間記錄
- 移動次數統計

**資料庫結構**：
- 自動建立資料庫和表結構
- 支援查詢和篩選
- 玩家統計功能

### ✅ 現代化 UI

**功能描述**：
使用 PyQt5 建立的圖形使用者介面。

**特色**：
- 清晰的視覺設計
- 即時狀態更新
- 響應式佈局
- 顏色編碼（數字顏色）
- 直觀的操作方式

## 開發中功能

**計劃功能**：

## 技術特色

### 模組化設計

- **核心邏輯分離**：遊戲引擎與 UI 分離
- **AI 模組獨立**：機率計算和策略模組化
- **易於擴展**：新功能易於添加

### 資料持久化

- **SQLite 資料庫**：輕量級、無需額外配置
- **自動初始化**：首次運行自動建立資料庫
- **資料完整性**：完整的資料驗證

### 跨平台支援

- **Windows**：完整支援
- **macOS**：完整支援
- **Linux**：完整支援
